# Сертификаты и удостоверения

Сюда складывайте сканы документов. После этого я добавлю их в раздел
«Сертификаты» на сайте.

## Форматы

- **JPG, PNG, WebP** — для предпросмотра прямо на сайте.
- **PDF** — можно, но на сайте будет кнопка «Открыть документ», без картинки-превью.

## Как называть файлы

Латиницей, без пробелов, по схеме `год-название.расширение`:

```
2026-elektromehanik-medoborudovanie.jpg
2026-elektromehanik-optika.jpg
2025-sterilizatory.jpg
2024-sosudy-davlenie.jpg
2023-videomontazh.jpg
2021-naladchik-chpu.jpg
2013-kladovshchik-1c.jpg
```

Так файлы не перепутаются и будут нормально открываться на любом устройстве.

## Пожелания к сканам

- Разрешение по длинной стороне — **1200–2000 px**, чтобы читался текст.
- Размер файла — до **2–3 МБ**.
- Сканируйте или фотографируйте ровно, без сильных бликов.
- Личные данные (паспорт, адрес), если они есть, можно закрыть — на сайте они не нужны.

## Что прислать вместе с файлами

Чтобы подписать карточки, нужны:

1. Точное название документа.
2. Кто выдал.
3. Год выдачи.
4. Номер и срок действия — по желанию (можно не публиковать).

Если каких-то данных нет — присылайте только файлы, остальное подпишу по названию.
