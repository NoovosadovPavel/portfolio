# Showreel

Сюда складываем видео для будущего раздела «Showreel» на сайте.

## Требования к файлам

- **Формат:** MP4 (H.264 + AAC) или WebM.
- **Размер одного файла:** до **100 МБ** — это жёсткий лимит GitHub. Лучше держаться в диапазоне 10–30 МБ.
- **Разрешение:** 1920×1080 или 1280×720, 24–30 fps.
- **Имена файлов:** `01-intro.mp4`, `02-production.mp4`, `03-service.mp4` и так далее. Нумерация задаёт порядок на странице.
- **Постеры:** рядом с видео можно положить кадр `01-intro.jpg` (16:9, 1280×720). Если постера нет — я вырежу его из видео.

## Если файл больше 100 МБ

GitHub не примет такой файл. Варианты:

1. Сжать видео (команда ниже).
2. Загрузить на YouTube или Vimeo и прислать ссылку — тогда на сайте будет встроенный плеер, а не файл в репозитории.

## Сжатие через ffmpeg

```bash
ffmpeg -i input.mov \
  -vf "scale=-2:1080" \
  -c:v libx264 -preset slow -crf 23 \
  -c:a aac -b:a 128k \
  -movflags +faststart \
  output.mp4
```

Для 720p замените `1080` на `720`. Если итоговый файл всё ещё большой, поднимите `-crf` до 26–28.
